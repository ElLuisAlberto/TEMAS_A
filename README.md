# Temas de Robótica Avanzada

Repositorio de laboratorios desarrollados para el curso **ING341 - Temas de Robótica Avanzada**.

Los proyectos están implementados con **ROS 2 Jazzy** sobre Ubuntu 24.04. Cada laboratorio se organiza en una carpeta independiente con su propio workspace, código fuente e instrucciones de ejecución.

## Laboratorios

| Laboratorio | Tema | Descripción |
|---|---|---|
| [LAB_02](LAB_02) | Gemelo digital de un manipulador | Modelado de manipuladores mediante URDF, visualización en RViz y control de articulaciones. |

## Requisitos generales

- Ubuntu 24.04
- ROS 2 Jazzy
- colcon

Cada laboratorio contiene un README con sus requisitos y comandos específicos.
